# **Как сдать работу**

Подготовьте пул-реквест со всеми изменениями, которые требуются для выполнения задания.

Проверьте, что реализовали все задания проектной работы.

## **Задание 1**

1. Диаграмма архитектуры системы в [draw.io](http://draw.io/).
2. Код в репозитории, реализующий PKCE flow.

## **Задание 2**

1. Диаграмма архитектуры системы в [draw.io](http://draw.io/).
2. Код в репозитории, связаный с Airflow в отдельную папку.
3. Добавлена имплементация для API для фактического сбора данных из ClickHouse.

Перед отправкой решения проверьте, что вы включили в пул-реквест все нужные файлы. Если всё готово, отправьте ссылку на пул-реквест во вкладке «Ревью».

Не забудьте проверить, что репозиторий публичный. Если создадите приватный репозиторий, ревьюер не сможет прокомментировать ваше решение и вернёт его на доработку.

После того как отправите ссылку, не вносите изменения в проект. Дождитесь комментариев ревьюера.
